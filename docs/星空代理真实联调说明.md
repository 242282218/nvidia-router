# 星空代理真实联调说明

本说明用于测试机验证星空代理租约、连接复用和所有 NVIDIA 端点。真实凭据只能通过运行时环境变量注入，不能写入 `.env`、脚本、日志、截图或 Git。

## 前置条件

- 已轮换曾经暴露过的星空 API 凭据，并启用星空账户的出口 IP 白名单。
- 代理池已在国内测试机健康运行，应用通过 `NVIDIA_ROUTER_XK_PROXY_URL` 连接其标准 HTTP 正向代理端口。
- 测试机已安装 Docker、Compose、Go、curl、Python 3 和 Bash。
- `NVIDIA_ROUTER_XK_PROXY_LIVE_LOG_PATH` 指向服务的脱敏结构化日志；日志不得包含代理 IP、API URL 或请求正文。

## 静态自测

```bash
bash -n scripts/test/live-nvidia.sh
NVIDIA_ROUTER_XK_PROXY_LIVE_SELF_TEST=1 bash scripts/test/live-nvidia.sh
```

自测只检查安全输出和临时文件权限，不访问星空或 NVIDIA。

## 真实运行

```bash
export NVIDIA_ROUTER_XK_PROXY_URL='http://<proxy-pool-host>:8080'
export NVIDIA_ROUTER_XK_PROXY_AUTH_KEY='<runtime-only proxy auth key>'
export NVIDIA_ROUTER_LIVE_BASE_URL='http://127.0.0.1:3756'
export NVIDIA_ROUTER_ADMIN_PASSWORD='<runtime-only admin password>'
export NVIDIA_ROUTER_LIVE_KEY='<runtime-only NVIDIA API key>'
export NVIDIA_ROUTER_LIVE_CHAT_MODEL='<enabled chat model public id>'
export NVIDIA_ROUTER_LIVE_EMBEDDING_MODEL='<enabled embedding model public id>'
export NVIDIA_ROUTER_XK_PROXY_LIVE_LOG_PATH='<脱敏服务日志路径>'
export NVIDIA_ROUTER_XK_PROXY_LIVE_REPEATS=20
bash scripts/test/live-nvidia.sh
```

脚本重复执行现有 NVIDIA 真实端点套件，输出只包含 case、状态、耗时和租约计数。它不会打印 URL、代理 IP、API Key、请求正文或响应正文。没有日志路径时，功能请求仍会运行，但租约指标会明确报告 `BLOCKED`，不能据此宣称连接复用或传输加速。

## 验收记录

分别记录直连基线、代理冷连接和同一租约热连接的成功率、P50/P95 首字节时间、完整响应时间、提取次数和每租约请求数。代理热连接 P95 不高于直连的 120%、成功率不低于 99%、吞吐不低于直连的 90%，且 165 秒可分配窗口内正常提取次数恰好为 1，才允许启用生产代理。跨越 180 秒的长 SSE/TTS 若被供应商中断，应更换更长 TTL 套餐，不增加重试代码。

## 清理与回滚

测试完成后删除临时容器、进程、访问 Key、测试 NVIDIA Key 和临时日志。回滚时清空 `NVIDIA_ROUTER_XK_PROXY_URL` 与 `NVIDIA_ROUTER_XK_PROXY_AUTH_KEY` 并重启服务，验证 NVIDIA 直连主路径；运行时设置迁移会由应用自动执行。

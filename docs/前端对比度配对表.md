# 前端对比度配对表

> 本表是 `web/src/styles/theme.css` 全部文本/背景配对的实算登记。任何新配对必须先经
> `python scripts/calc_contrast.py` 实算通过后才能进入代码；改色值必须同步更新脚本与本表。

- 算法：WCAG 2.x 相对亮度（sRGB，阈值 0.03928），`(L亮 + 0.05) / (L暗 + 0.05)`。
- 正文类配对要求 ≥ 4.5:1；非文本 UI（焦点环、控件描边、图表数据色）≥ 3:1。
- 运行：`python scripts/calc_contrast.py`（无参数打印全部配对并返回退出码）。
- 当前结果：**88/88 pairs pass**（Light 47 + Dark 41）。

## 备注

- 品牌 NVIDIA 绿在两套主题中同值（`#76b900`），仅限 Logo/品牌徽章，不作正文色。
- 暗色 tint 底用 `color-mix(... var(--color-surface))` 而非混白，脚本以
  `_tint_on_surface()` 复现同一公式保证可复算。
- 阴影、遮罩、滚动条、选区等非文本装饰色不承担对比度义务，不在本表登记。
- Warm Studio 光效通道（`--glow-accent`、`--hairline`、`--border-glow-*`、纸纹噪点）
  均为纯装饰（光晕/发丝线/流光描边/颗粒），不承载文本与控件边界语义，无对比度义务；
  hover 渐变描边出现的同时必有阴影提升作为第二 affordance。

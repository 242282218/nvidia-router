# 前端对比度配对表

本表是 `web/src/styles/theme.css` 全部 token 配对的**唯一实算登记处**（依据：设计美学知识库 `00-基础判断/对比度配对表.md` 的硬约束——表外配对不许用，改 token 后必须重算）。

- 计算工具：`python scripts/calc_contrast.py`（WCAG 2.x 相对亮度公式，阈值 0.03928）
- 首次实算日期：2026-08-16，39/39 配对通过
- 主题：暗色单模式，NVIDIA 绿强调（`#76b900` 品牌色，非框架默认色）

## 阈值

| 用途 | 阈值 |
|------|------|
| 常规尺寸文本 | ≥ 4.5:1 |
| 大文本（≥24px 常规 / ≥18.66px 粗体）、控件边界、图标、焦点环 | ≥ 3:1 |
| 纯装饰分隔线 | 无要求 |

## 图表数据色

趋势图为**单系列语义图**（每图一线，颜色承载状态语义而非类别区分）：failures=`--color-danger`（虚线第二编码）、latency=`--color-warning`、tokens=`--color-success`、requests=`--color-info`。上述四色对 canvas/surface 实测 6.26~11.17:1，全部 ≥3:1 ✅（见上表）。数值第二出口：每图底部 `<details>` 数据表，不依赖 hover。

## 维护协议

1. 改 `theme.css` 任何色值 → 同步改 `scripts/calc_contrast.py` 顶部常量 → 重跑 → 更新本表比值与日期。
2. 新增配对（含图表数据色、新底色）→ 先补进脚本 `PAIRS` 并实算，通过后才允许在组件中使用。

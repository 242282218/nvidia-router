```go
// 核心设计思想
type Pool struct {
    accounts  []*Account           // 账户列表
    queue     chan *Account        // 等待队列
    maxActive int                  // 最大并发
    queueSize int                  // 队列大小
    mu        sync.RWMutex
}

// 亮点 1: 等待队列机制
func (p *Pool) Acquire(ctx context.Context) (*Account, error) {
    select {
    case acc := <-p.queue:
        return acc, nil
    case <-ctx.Done():
        return nil, ctx.Err()
    }
}

// 亮点 2: 使用完归还队列尾部 (LRU 轮转)
func (p *Pool) Release(acc *Account) {
    p.queue <- acc  // 放回队尾,实现轮转
}

// 亮点 3: 全局并发限制
func (p *Pool) SetMaxActive(max int) {
    p.mu.Lock()
    defer p.mu.Unlock()
    p.maxActive = max
    // 动态调整队列大小
}
```

**设计优点**:
- ✅ 无可用账户时排队而非立即失败
- ✅ 队列大小控制,避免无限等待堆积
- ✅ LRU 策略,账户使用更均匀
- ✅ 运行时动态调整限流参数

**适用场景**: 资源有限且获取成本高的场景(如账户登录态)

// 核心设计思想
type Switcher struct {
    current atomic.Value  // *ProxyHandle
    mu      sync.Mutex
}

// 亮点 1: 原子切换,无锁读取
func (s *Switcher) Get() *ProxyHandle {
    return s.current.Load().(*ProxyHandle)
}

// 亮点 2: 优雅关闭旧连接
func (s *Switcher) Switch(newProxy *Proxy) error {
    s.mu.Lock()
    defer s.mu.Unlock()
    
    oldHandle := s.current.Load().(*ProxyHandle)
    newHandle := &ProxyHandle{proxy: newProxy}
    
    s.current.Store(newHandle)
    
    // 旧连接优雅关闭
    go func() {
        time.Sleep(30 * time.Second)  // 等待已有请求完成
        oldHandle.Close()
    }()
    
    return nil
}
```

**设计优点**:
- ✅ 热切换,不中断服务
- ✅ 原子操作,读取无锁
- ✅ 旧连接优雅关闭,不丢请求

func (h *HealthChecker) Probe(proxy *Proxy) error {
    req, _ := http.NewRequest("GET", h.targetURL, nil)
    
    // 关键: 绕开缓存,强制真实请求
    req.Header.Set("Cache-Control", "no-cache")

        return err
    }
    defer resp.Body.Close()
    
    if resp.StatusCode != 200 {

    }
    
    return nil
}

// 运行时配置写入文件
func (c *Config) Persist(path string) error {
    data, err := json.MarshalIndent(c, "", "  ")
    if err != nil {
        return err
    }
    
    // 原子写入(先写临时文件再重命名)
    tmpPath := path + ".tmp"
    if err := os.WriteFile(tmpPath, data, 0600); err != nil {
        return err
    }
    
    return os.Rename(tmpPath, path)
}

// 启动时加载
func LoadOrDefault(path string) (*Config, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        if os.IsNotExist(err) {
            return DefaultConfig(), nil  // 使用默认配置
        }
        return nil, err
    }
    
    var cfg Config
    if err := json.Unmarshal(data, &cfg); err != nil {
        return nil, err
    }
    
    return &cfg, nil
}
```

**设计优点**:
- ✅ 运行时配置持久化
- ✅ 重启后自动恢复
- ✅ 原子写入,防止损坏

##### 2.4 流式响应空闲超时检测

```go
// 亮点: 检测流式响应长时间无数据
type IdleTimeoutReader struct {
    r           io.Reader
    timeout     time.Duration
    lastRead    time.Time
    mu          sync.Mutex
}

func (r *IdleTimeoutReader) Read(p []byte) (int, error) {
    r.mu.Lock()
    if time.Since(r.lastRead) > r.timeout {
        r.mu.Unlock()
        return 0, ErrIdleTimeout
    }
    r.mu.Unlock()
    
    n, err := r.r.Read(p)
    if n > 0 {
        r.mu.Lock()
        r.lastRead = time.Now()
        r.mu.Unlock()
    }
    
    return n, err
}
```

**设计优点**:
- ✅ 检测流式响应卡住
- ✅ 避免连接长时间挂起
- ✅ 适用于 SSE/Streaming 场景

### 设计差异与优化 🔄

#### 1. 资源池模型差异

**ds2api**: 账户池 - 有限资源,获取成本高
```go
// 等待队列模型
type Pool struct {
    queue chan *Account  // 阻塞等待
}
```

**nvida反代**: 代理池 - 外部提供,可批量获取
```go
// 立即失败 + 轮换模型
type Pool struct {
    available []*Proxy  // 立即返回或失败
    rotationIndex uint32  // 原子轮换
}
```

**为什么不采用等待队列**:
- ✅ 代理获取成本低(外部API批量提供)
- ✅ 立即失败对反代场景更合适(用户不愿等待)
- ✅ 可以通过定时采集补充代理池

#### 2. 配置持久化增强

**opencode_zen**: 文件持久化
```go
json.MarshalIndent(config, "", "  ")
os.WriteFile(path, data, 0600)
```

**nvida反代**: 数据库持久化 + 加密
```go
// 更安全,更适合生产
ciphertext, nonce, err := s.keys.Encrypt(plaintext, AAD)
s.db.ExecContext(ctx, "INSERT INTO proxy_pool_settings ...")
```

**为什么更优**:
- ✅ 数据库事务保证一致性
- ✅ 敏感信息加密存储(authKey)
- ✅ 支持集群部署(共享配置)

#### 3. 健康检查增强

**opencode_zen**: 简单 HTTP 探测
```go
resp, err := client.Do(req)
return resp.StatusCode == 200
```

**nvida反代**: 延迟测量 + EWMA 优化
```go
// 不仅检查可用性,还优化延迟
start := time.Now()
resp, err := client.Do(req)
latency := time.Since(start)

// EWMA 平滑延迟
proxy.LatencyEWMA = alpha*latency + (1-alpha)*proxy.LatencyEWMA
```

**为什么更优**:
- ✅ 识别慢速代理
- ✅ 优先使用快速代理
- ✅ EWMA 平滑抖动

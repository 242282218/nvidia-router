# 前端全量重构设计 —— 暖纸工作室（Warm Studio）

日期：2026-08-21。状态：已确认（用户逐节批准）。

## 目标与范围

在保留暖纸风基调的前提下全量重构前端与交互，追求 2026 年管理面板的前沿高级感。
范围：12 个功能模块约 30 个视图全部迁移；后端零改动，`contract.spec.ts` 零改动。

## 已确认决策

| 决策点 | 结论 |
|---|---|
| 设计方向 | 延续暖纸风深度打磨（不转深色科技风） |
| 范围 | 全量重构 |
| 依赖 | 引入精选轻库：motion-v、lucide-vue-next；图表保持手写 SVG |
| 字体 | 不自托管字体，继续系统字体栈 |
| 交互重点 | 微交互动效 + 键盘优先 + 数据可视化升级 + 表格密度体验，四项全做 |
| 策略 | 方案 A：设计系统优先，分五阶段迁移 |

## 设计语言 v3

- 层级：新增 `--color-canvas-deep`（页面底）与 `--color-surface-raised`（悬浮层），卡片真正浮起。
- 材质：SVG feTurbulence 极低透明度纸纹噪点铺画布；卡片顶部发丝高光线。
- 光效：hover 渐变描边流光（暖琥珀→品牌绿）、主按钮语义色环境光晕，限定暖色调。
- 阴影：多层暖调柔影升级。
- 动效：motion-v 弹簧物理（按压 scale、弹窗 spring、抽屉弹簧、列表 FLIP）；页面过渡退出 blur+位移、进入 stagger 上浮；reduced-motion 全局降级。

## 组件与体系

- Ui* 升级（API 兼容）：UiButton spring 按压+光晕、UiCard hover 渐变描边、UiModal spring 缩放、UiTabs/segment 滑动指示器。
- 新增：UiKbd、UiTooltip、UiProgressRing、UiCopyField。
- 图标：icons.ts 改为 lucide-vue-next 精选再导出，调用点不动。
- 表格 v2（新 UiDataTable）：吸顶表头、列排序、行多选+浮动批量操作条、密度切换、@vueuse useVirtualList 虚拟滚动；移动端沿用卡片模式。
- 图表套件（新 shared/charts/）：ChartArea（泛化自 MonitoringTrendChart）、ChartBars、ChartDonut、ChartHeatmap、Sparkline 抽出共用；只用现有 API 数据字段。
- 键盘优先：命令面板 v2 动作注册表；列表页 `?create=1` 直达新建弹窗；全局快捷键 ⌘K / ? 帮助 / `/` 聚焦筛选 / Esc 分层关闭。

## 页面要点

- AppShell：侧栏精修、桌面可折叠图标栏、移动抽屉弹簧化；登录页加噪点+spring 入场+错误抖动。
- 监控统计：KPI bento 网格、ChartArea 趋势、结果分布环图（success/canceled/failure）、成本热力图、日志表 v2。
- Live：流式卡片流 spring 滑入、连接呼吸灯。
- 代理池：健康度大环 gauge 锚点 + 出口表 v2。
- 资源管理页：统一表格 v2 + 批量操作条；Key 揭示交互；ModelsView 拆 composables。
- 审计：竖向时间线；系统观测 Tab 用滑动指示器分段控件。

## 红线（不可妥协）

- 对比度：新配对先跑 `scripts/calc_contrast.py` 并登记 `docs/前端对比度配对表.md`。
- UnoCSS 任意值禁 alpha 修饰符（`bg-[var(--x)]/50`），半透明一律 color-mix。
- pointer-coarse 触控目标 ≥44px；ESLint DOM 全局写 `globalThis.*`。
- testId 保持稳定；vitest 中含懒加载组件的 router.push 用 spy 断言。
- 每阶段 lint/typecheck/test/build 全绿 + `go build ./...` 验证 embed；产物重建进 `internal/web/dist` 后跑 `scripts/check-web-dist.sh`。

## 阶段划分

① 地基（依赖/token/图标/新组件/图表/表格/键盘）→ ② 壳层（AppShell/登录/面板）→ ③ 高频页（监控/Live/代理池）→ ④ 资源管理页 → ⑤ 观测页+收尾。每阶段独立验证并提交。

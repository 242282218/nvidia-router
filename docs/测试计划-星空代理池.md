## 第二阶段:测试机部署

### 2.1 部署准备

```bash
# SSH 连接测试机
ssh -p 22 root@149.71.241.250

# 进入项目目录
cd /path/to/nvida反代

# 拉取最新代码
git fetch origin
git checkout feat/nvidia-router-mvp
git pull origin feat/nvidia-router-mvp

# 查看变更
git log --oneline -5
```

### 2.2 配置环境变量

创建或更新 `.env` 文件:

```bash
# 模式选择(二选一)

# 方案A: 内置代理池模式(新)
NVIDIA_ROUTER_XK_UPSTREAM_URL=https://api.xingkongdaili.com/api/getproxy/...
NVIDIA_ROUTER_XK_VALIDATION_URL=https://integrate.api.nvidia.com/v1
NVIDIA_ROUTER_XK_VALIDATION_STATUS=404
NVIDIA_ROUTER_XK_PROXY_TTL=120s
NVIDIA_ROUTER_XK_COLLECT_INTERVAL=5s
NVIDIA_ROUTER_XK_CONCURRENCY=2

# 方案B: 外部代理池模式(兼容)
NVIDIA_ROUTER_XK_PROXY_URL=http://127.0.0.1:8080
NVIDIA_ROUTER_XK_PROXY_AUTH_KEY=your-auth-key

# 必需配置(两种方案都需要)
NVIDIA_ROUTER_MASTER_KEY=<your-master-key>
NVIDIA_ROUTER_INITIAL_ADMIN_PASSWORD=<your-password>
```

### 2.3 编译运行

```bash
# 编译
go build -o nvidia-router ./cmd/nvidia-router

# 运行(前台测试)
./nvidia-router serve

# 或使用 Docker Compose
docker compose up --build
```

### 2.4 验证日志

观察以下关键日志:

```bash
# 内置池模式应看到:
upstream_fetch_start
upstream_fetch_success count=2
proxy_validation_failed (debug级别,正常)
pool_updated validated_count=N pool_size=N

# 外部代理模式应看到:
proxy_manager_initialized
```

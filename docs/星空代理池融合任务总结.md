### 2. 架构设计

#### 当前模式
- **单体内置池**：直接对接 XApi，完成采集、验证、TTL、轮换和 CONNECT。
- 旧外部 HTTP 正向代理模式已废弃。

#### 核心特性
1. **TTL 淘汰**:代理过期立即剔除,本地 TTL 120s
2. **失败隔离**:短暂隔离而非直接删除,渐进恢复
3. **Panic 模式**:全部隔离时忽略隔离保证可用性
4. **会话粘滞**:同一会话固定出口,避免 IP 跳变风控
5. **延迟优化**:慢速代理自动降级
6. **错误分类**:限流、账户、传输错误分别处理

## 风险与注意事项

### 已知限制
1. 多实例独立采集(不共享池)
2. 重启后池状态丢失(需重新采集)
3. 依赖星空白名单配置(出口 IP)

1. 先在测试环境验证内置池模式
2. 监控采集成功率和池容量

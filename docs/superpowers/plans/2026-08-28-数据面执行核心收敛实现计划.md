# 数据面执行核心收敛实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `subagent-driven-development` 或按本计划逐任务实现。每个任务结束都必须运行该任务列出的测试。

**目标：** 收敛 OpenCodeFree Chat/Responses 的 provider 调用、重试和错误映射，同时保持现有 Chat、Responses、NVIDIA Attempt 和公开错误契约不变。

**架构：** 在 `internal/httpapi/v1` 增加一个小型 OCF 执行策略组件，负责 attempt 生命周期、首字节提交保护和共享状态分类；Chat 与 Responses 仅提供协议 callback。NVIDIA 的 Key 池重试不迁移，只用同一组错误语义测试约束。

**技术栈：** Go 1.24、`net/http`、现有 `fault`/`apierror`/`sse`/`nvidia.ValidateNonstreamChat`，不新增依赖或 migration。

- [x] **步骤 1：实现最小策略**

实现只负责：

```go
type openCodeFreeExecution struct {
    call func(context.Context, bool) (*http.Response, error)
```

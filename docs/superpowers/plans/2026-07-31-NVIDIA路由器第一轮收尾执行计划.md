func isAudioContentType(value string) bool {
	mediaType, _, err := mime.ParseMediaType(value)
	if err != nil {

	return strings.HasPrefix(mediaType, "audio/") || mediaType == "application/octet-stream"
}

- [ ] **步骤 2：登录后真正导入 `NVIDIA_ROUTER_LIVE_KEY`**

在 `AdminLogin` PASS 后立即调用：

```text
POST /admin/api/nvidia-keys
Content-Type: application/json
Cookie: nvr_admin_session=<session>

{"key":"<环境变量 NVIDIA_ROUTER_LIVE_KEY 的值>"}
```

请求体只能由 Python 从进程环境构造，不能通过 `echo` 或日志输出；调用完成后立刻 `unset NVIDIA_ROUTER_LIVE_KEY`。仅接受 HTTP `201` 且 JSON `status` 为 `imported` 或 `duplicate`；其他状态输出 `ImportNVIDIAKey FAIL` 并退出。 `imported` 时从 `key.id` 取得 ID 并标记为脚本拥有；`duplicate` 时使用响应的 `masked` 值从 `GET /admin/api/nvidia-keys` 找到唯一启用且 `auth_invalid=false` 的 ID，不删除原有 Key。

4. 再次 GET 模型列表，确认 Audio 模型已启用且时间戳存在，并把时间戳放入进程环境供 `tests/live` 判断。

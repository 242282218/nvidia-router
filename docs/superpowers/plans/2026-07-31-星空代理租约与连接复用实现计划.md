# 星空代理租约与连接复用实现计划

> **面向 Codex 的工作者：** 按本计划逐任务执行；每个任务先写失败测试，再写最少实现，完成后运行该任务的验证命令。保留当前工作区已有未提交改动，不执行还原或重写。

**目标：** 在配置星空代理时为所有 NVIDIA 上游端点提供全局单 IP 租约、租约级长连接复用和一次代理故障重放，同时保持直连模式和现有 NVIDIA Key 调度语义不变。

**架构：** `internal/xkproxy` 直接实现星空 Fetcher 和租约 Manager。Manager 负责懒提取、165 秒可分配窗口、引用计数、按稳定超时组合缓存 `http.Transport` 和故障退役；`internal/upstream/nvidia.Client` 通过一个共享 `do` 发送器使用 Manager，端点只提供可重建请求 factory。代理错误在 `Attempt`、Key 验证、模型发现/验证和 HTTP handler 边界统一识别并脱敏。

**技术栈：** Go 标准库 `net/http`、`net/http/httptrace`、`net/netip`、`sync/atomic`、现有 `internal/clock` 与 `runtimeconfig`；Docker Compose；Bash/Python 仅用于真实联调脚本。不新增生产第三方依赖或数据库迁移。

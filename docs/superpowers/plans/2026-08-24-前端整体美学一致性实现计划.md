# 前端整体美学一致性实现计划

> **面向 AI 代理的工作者：** 本计划在当前仓库的 `codex/ui-aesthetic-consistency` 分支内执行；遵循既有前端测试、构建和嵌入产物校验规则。项目规则要求默认不提交，完成后仅报告变更与验证结果。

**目标：** 在不改变业务行为、路由和 API 契约的前提下，把 Warm Paper / Flat Outline 视觉语言收敛为“精确、克制、可靠”的统一管理台体验。

**架构：** 复用现有 CSS token、UnoCSS shortcut 和 Vue 共享组件，先以 `AppShell + ModelHealthView` 作为代表性切片，验证页面骨架、状态表达、数据卡片和响应式，再把已验证的 token 用法推广到资源接入、系统观测和认证页面。只修复已有局部例外，不新增组件层级或视觉依赖。

**技术栈：** Vue 3、TypeScript strict、UnoCSS、Vite、Vitest、现有 Lucide 图标与 Playwright/视觉 QA 脚本。

## 设计约束

- 主签名：语义 token 与 Flat Outline 组件语言；不使用阴影、backdrop blur、渐变装饰或 `dark:` 变体。
- 颜色：组件模板不直接写状态 hex；状态、文本、surface、边界全部从 `theme.css` 语义 token 取值；新增配对先运行 `scripts/calc_contrast.py`。
- 圆角：面板使用 `--radius-panel`，控件使用 `--radius-control`，浮层使用 `--radius-overlay`；`rounded-full` 仅保留给徽章、头像、状态点、进度条等语义明确的胶囊/圆形。
- 字体：页面标题、区块标题、标签、KPI 数字继续使用 `type-title/type-heading/type-label/type-display`，数据字段继续使用 `font-mono-data`。
- 响应式：1440px、1024px、390px 均须有明确布局；可滚动表格只在自身容器内滚动；移动抽屉、Modal、菜单和 tooltip 必须保持视口内可用。
- 行为：保持 API、路由、`data-testid`、键盘路径、触控尺寸、焦点可见性和 reduced-motion 行为不变。

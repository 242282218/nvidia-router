# 扁平化遮罩与浮层修复实现计划

> 面向 AI 代理的工作者：本计划按 TDD 执行。当前仓库已有用户未提交改动，不执行 reset、checkout 或批量恢复；实现默认不提交，除非用户另行要求。

目标：在保留现有 Vue 组件边界和焦点契约的前提下，移除前端拟物阴影/模糊/光晕残留，并修复 tooltip、menu、modal 和固定工具条在桌面与移动视口中的裁切和遮挡。

架构：新增一个无副作用的水平浮层定位纯函数，供图表和模型健康卡复用；共享浮层继续使用现有组件和 z-index 层级，不引入 Portal 或第三方定位库。视觉基线集中在 theme.css 与 UnoCSS shortcuts，具体组件只保留语义状态色和必要的交互反馈。

技术栈：Vue 3 + TypeScript + UnoCSS + Vitest/happy-dom + Vite + Playwright。

- [ ] 步骤 3：编写最少实现

    export type HorizontalPlacement = 'start' | 'center' | 'end'

    export function horizontalPlacement(position: number, width: number): HorizontalPlacement {
      if (width <= 0) return 'center'
      const ratio = position / width
      if (ratio <= 0.25) return 'start'
      if (ratio >= 0.75) return 'end'
      return 'center'
    }

# vibe 场景模型优化实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或当前会话内逐任务执行本计划。步骤使用复选框（- [ ]）语法跟踪进度；实现默认不提交或推送，除非用户另行授权。

**目标：** 将 vibe 场景评测中发现的代理瞬态失败、流式截断、工具能力元数据漂移和上下文声明缺失，收敛为可解释、可重试、可按模型验收的运行链路。

**架构：** 保留现有 NVIDIA Attempt 作为唯一 Key/代理切换入口，保留 Chat、Responses、OpenCodeFree 的 provider 边界；在模型目录增加工具能力的验证状态，在请求解析前完成能力门禁；评测脚本只输出脱敏指标，由国内测试机真实矩阵验证最终行为。

**技术栈：** Go 1.24 + SQLite migrations + Vue 3/TypeScript + Vitest + Playwright + Python 3 标准库 + Docker Compose。

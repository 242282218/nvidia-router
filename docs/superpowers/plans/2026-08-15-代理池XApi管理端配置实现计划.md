# 代理池 XApi 管理端配置实现计划

> **面向 AI 代理的工作者：** 本计划在当前工作区内执行；不要覆盖已有未提交改动，不要提交或输出真实 XApi 凭据。每个生产代码改动前先完成对应的失败测试。

**目标：** 让管理员可以在代理池页面录入 XApi 完整地址，服务端用主密钥加密持久化，并在保存后立即热切换内置代理池。

**架构：** 复用现有 \`/admin/api/proxy-pool\` PATCH 接口、\`SettingsService\` 和代理池配置表。为 XApi URL 增加独立的 nonce/ciphertext 字段和独立 AAD；GET 只返回是否配置及脱敏后的 endpoint，绝不返回查询凭据。没有数据库配置时继续支持运行时环境变量作为兼容回退。

**技术栈：** Go 1.24、SQLite、现有 \`internal/crypto.KeySet\`、Vue 3 + TypeScript、Vitest。

### 任务 3：实现 XApi URL 校验、加密、加载与热切换

**文件：**
- 修改：\`internal/xkproxy/settings.go\`
- 修改：\`internal/xkproxy/settings_test.go\`

- [ ] **步骤 1：扩展输入与内部存储类型**

复用现有 \`Patch.UpstreamURL *string\` 的字段存在性：非空表示替换，显式空值表示清除；为 \`storedProxyConfig\` 增加 XApi nonce/ciphertext，并使用独立常量 \`proxyPoolUpstreamURLAAD\`。完整 URL 只存在于当前调用和 manager/collector 内存中。

- [ ] **步骤 2：实现最小 URL 校验**

复用现有 \`net/url\` 解析模式，要求绝对 \`http\`/\`https\`、有 host、有 query，无 userinfo、无 fragment；错误只返回通用字段校验信息，不拼接原始 URL。

- [ ] **步骤 3：让 built-in 模式可脱离环境变量启动**

数据库存在 built-in sentinel 且有 XApi 密文时，从密文恢复 URL；安全参数从 \`pool_config\` 恢复，无安全参数时使用现有默认值。环境变量 XApi 仍作为没有数据库密文时的兼容回退。

- [ ] **步骤 4：实现加密持久化与清除**

使用 \`KeySet.Encrypt\`/\`DecryptVersion\` 和独立 AAD；加密前后对明文、nonce、ciphertext 做清零。保存配置时使用参数化 SQL；清除只在代理池 disabled 时允许，并清空对应两列。

- [ ] **步骤 5：运行后端绿灯测试**

运行：

~~~powershell
go test ./internal/xkproxy ./internal/httpapi/admin
~~~

预期：任务 1 的测试全部通过，且现有静态代理、环境变量回退、代理池安全参数测试不回归。

# 星空代理池静态接入实现计划（已废弃）

> 本计划对应历史独立代理池方案，当前目标已改为单体内置模式；不要按本文件部署或验收。

> **面向 AI 代理的工作者：** 必需子技能：按本计划逐任务执行；每个任务先写失败测试，再写最少实现并验证。

**目标：** 将 `nvida反代` 从 XApi 提取单个代理 IP 改为连接 `星空代理池` 的标准 HTTP 正向代理，并删除旧 API/租约/管理配置链路。

**架构：** `config` 读取代理池端点和认证 Key；`xkproxy.Manager` 构造带 Basic 认证的共享 `http.Transport`；NVIDIA 客户端继续复用现有代理失败重试。代理池独立负责 XApi、出口轮换、测活和 TTL。本项目不读取 `xk_proxy_settings`，历史迁移文件保留用于数据库版本兼容。

**技术栈：** Go 1.24、标准库 `net/http`、SQLite 迁移、Vue 3 + TypeScript + pnpm、Docker Compose。

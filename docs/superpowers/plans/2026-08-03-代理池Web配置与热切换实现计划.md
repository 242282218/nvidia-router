# 代理池 Web 配置与热切换实现计划

## 目标

为管理台增加代理池配置入口，认证 Key 使用现有主密钥加密落库，配置保存后热切换运行时代理；无数据库配置时保留环境变量兜底，并重新部署到国内服务器。

## 执行步骤

1. 新增 `proxy_pool_settings` 迁移，并先补数据库、加密和热切换失败测试。
2. 实现代理配置存储/校验/加密服务，接入 `xkproxy.Switcher`，保证切换期间旧请求继续完成、启用失败不直连。
3. 接入 App 生命周期和管理员 `GET/PATCH /admin/api/proxy-pool`，认证 Key 不回显、不写日志。
4. 增加 Vue 代理池页面、路由、侧栏入口和表单测试。
5. 执行 Go 与前端全量验证、构建嵌入静态资源，修复回归。
6. 备份国内服务器数据卷，构建新镜像并滚动重建容器，验证健康检查、管理台和公网访问。

## 验收标准

- 数据库只保存认证 Key 的 nonce/ciphertext，错误主密钥启动失败。
- 数据库配置优先于环境变量；没有数据库行时返回 `source=environment`，都没有时为 `none`。
- 保存配置后新请求立即使用新代理，旧请求不被切断；启用代理不可静默直连，显式禁用后才允许直连。
- 管理台出现“代理池”，支持启用/禁用、地址、保存/清除 Key，Key 内容不显示。
- `go test ./...`、`go vet ./...`、前端 lint/typecheck/test/build 和 `git diff --check` 通过。
- 国内服务器 `http://114.55.25.190:3756/admin/` 公网可访问，`/health/live` 与 `/health/ready` 返回 200。

# 原生能力透传实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用内联执行完成本计划。步骤使用复选框跟踪进度。

**目标：** 让 Chat 请求的能力字段由 NVIDIA API 原生判定，反代不再根据本地 `supports_*` 元数据提前拦截或改写。

**架构：** 保留 JSON、消息、工具结构和请求大小校验，保留 Access Key、模型白名单及公开模型到上游模型 ID 的映射；`MarshalFor` 只替换 `model` 字段，不再检查本地能力标记，也不把 `thinking` 转换为 `reasoning_effort`。上游返回的能力错误直接沿用现有上游错误处理。

**技术栈：** Go 1.24、标准库 JSON、现有 Go 单元测试。
